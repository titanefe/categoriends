# SEO Strategy

## In scope
- Public landing page (`/`)
- Public feature-entry pages (`/daily`, `/solo`, `/room/create`, `/room/join`)
- Shared sitewide HTML shell and crawlability files (`index.html`, `robots.txt`, `sitemap.xml`, manifest, social tags)

## Out of scope
- Active gameplay flow (`/game`)
- Post-game results (`/result`)
- Dynamic room lobby URLs (`/room/:code`)
- Authenticated state, leaderboard persistence, and API internals except where they affect crawlability

## Target audience
- People searching for online category games, word games, party games, and multiplayer trivia games.
- English- and Turkish-speaking players.

## Primary keywords
- category game
- word game
- online category game
- multiplayer word game
- kategori oyunu
- kelime oyunu
